# 画布 Agent Golden Set 构建文档 · 总览索引

本目录是**人工撰写工作区**，不是跑测资产。用户逐条审阅确认后，再转成跑测用的 YAML。

- 契约依据：`agent-eval-platform/standards/canvas-agent.yaml` v1.0
- 方法论依据：`agent-eval-platform/docs/Agent-Skill评测方法论与指标体系.md` 第 5 节
- 被测对象：画布 Agent（Echo / CodeX / Hermes 三者之一或多个，**本轮不指定**，用例按三者通用书写）

## 本轮口径声明

| 项 | 口径 |
|---|---|
| 本轮规模 | **50 条**，为第一轮实践子集。契约 `goldenTarget: { minCases: 120, maxCases: 400 }` 不变，跑通后泛化补足到 120+ |
| 场景占比 | 以方法论 5.1 **占比表**为准（正文「核心逻辑为其他场景之和 2–3 倍」与占比表矛盾，已裁定弃用） |
| 起始状态 | **全部用例从空白画布开始**，不使用 fixture 文件（`fixtures/` 已删除） |
| 前置状态构造 | 用**多轮对话**在前几轮搭好，最后一轮为被测轮；能一轮完成的用一轮 |
| 预算口径 | **只设用例级总预算**，不按轮拆分 |
| 步数限制 | 不受任何单一 Agent 机制上限约束（Echo 的 4 步上限暂不作为设计约束） |
| 目标 YAML 结构 | 对齐方法论 5.5 推荐 Schema + 契约字段，**不对齐**现有评测平台的 `eval-case.ts` |

## 五、人工编辑规范

### 5.1 每条用例的表格结构

```
### <ID> · <标题>
元信息表 → 多轮对话表 → 被测轮期望表 → 用例级总预算 → 判据与依据 → 人工审阅
```

- **多轮对话表**：`轮次 | 用户消息 | 轮次用途 | 该轮期望画布变化`。`轮次用途` 只能填「铺状态」或「被测」。
- **只有被测轮承载判据**；铺状态轮的「该轮期望画布变化」只作为该轮成功的最小校验，不参与评分。
- 修改用例时若增删轮次，记得同步更新本文件 ID 总表的「轮数 / 被测轮」两列。

**story-only 节点**（`projectTypes: ["story"]`）：`game` / `story-chapter` / `story` / `story-choice` / `story-checkpoint` / `story-attribute` / `story-attribute-gate` / `timeline-editor`
**插件节点**（`projectTypes: ["content","story"]`，**两种画布都合法**）：`plugin:sticky-note` / `plugin:markdown` / `plugin:panorama`

> 重要：插件节点在 content 画布是**合法**的，不要写成越界用例。

**唯一不允许 Agent 创建的节点类型**：`timeline-editor` —— 注册表中该定义**没有 `agent` 字段**（`menu.group: "hidden"`，描述为「时间轴剪辑器，当前隐藏」），是拒绝原因 `node-type-agent-forbidden` 的唯一真实触发对象。

**运行态连线 kind**（仅 story 画布）：`flow` / `story-choice` / `game-outcome`
> 其他 kind（如 reference、generation）不在运行态白名单，**不会**触发越界拒绝。

**节点默认 metadata（写用例引用字段时的依据）**：

| 节点类型 | 关键 metadata 字段 |
|---|---|
| text | `content`, `status`, `fontSize` |
| image / video / audio | `content`（媒体 URL）, `status` |
| config | `content`, `status`, `generationMode`（默认 image） |
| story-chapter | `storyTitle`（默认「第一章」）, `storyText` |
| story | `storyText`（结局节点另用 `storyEndingType`: normal/good/bad/hidden） |
| story-choice | `storyChoices[]`，默认 `[{id:"choice_1",label:"选项一"},{id:"choice_2",label:"选项二"}]` |
| story-checkpoint | `storyCheckpointKey`（默认 slot_1） |
| story-attribute | `storyAttributes[]`，默认含 `favor`(50) / `sanity`(60) |
| story-attribute-gate | `storyAttributeKey`, `storyAttributeOperator`, `storyAttributeValue`；运行态端口 outcomeId 为 `pass` / `fail` |
| game | `gameConfig.gameplayId`，gameplayId ∈ puzzle / timed-puzzle / rapid-tap / quiz / dialogue-choice / spot-difference |
| plugin:sticky-note | `content`, `stickyColor`（默认 #fff2b2） |
| plugin:markdown | `content`（Markdown 源文）, `markdownEditing` |
| plugin:panorama | `prompt`（画面描述写这里）, `content`（只填已存在的全景图 URL）, `generationMode` |

**outcomeId 取值规则**：`story-choice` 连线的 outcomeId 必须来自目标选择节点 `metadata.storyChoices[].id`；`game-outcome` 连线的 outcomeId 必须来自目标游戏节点 gameConfig 的 outcome id；属性门禁分支用 `pass` / `fail`。
