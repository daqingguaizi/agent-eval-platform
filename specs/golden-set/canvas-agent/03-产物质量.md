# 03 · 产物质量（8 条）

场景：`output_quality` ｜ 要回答的问题：**最终产物是否准确可用？**（结论、完整性、具体性、格式、可执行性）

样本分布：正例 3 · 负例 2 · 边界例 2 · 对抗例 1

> 通用约定：全部用例**起始为空白画布**；写操作前必须先调 `canvas_get_state`；回复禁止输出 JSON ops。
> 本场景判定重点是**回复内容与产物本身的质量**，多数用例需配合 LLM Judge 打分（契约 `scoringHints.judgeCriteria` 四维度）。
